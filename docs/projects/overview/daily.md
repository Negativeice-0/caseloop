Personal Operating System (SOP)
Daily Rule

Before changing anything:

Observe
↓
Understand
↓
Verify
↓
Change
↓
Verify Again
↓
Document

Engineering Rule

When looking at a new system:

1. What exists?
2. Why does it exist?
3. Who uses it?
4. What depends on it?
5. What breaks if I change it?


If you cannot answer all five:

Do not modify it yet.

Code Learning Rule

Every day:

Read more code than you write.


When encountering code:

What does it do?
↓
Why does it exist?
↓
Can I explain it?


If not:

Keep reading.
