# CASELOOP NO-AI DAY

Goal:

Develop independent engineering ability.

Assume:

No GPT
No Copilot
No AI Assistance

Available:

Documentation
Compiler
Debugger
Terminal
Git
Notebook

------------------------------------------------

Challenge

Solve the task using only:

Code
Reasoning
Documentation

------------------------------------------------

Before starting:

Write:

What do I know?

What do I think?

What can I verify?

What assumptions exist?

------------------------------------------------

Level 1

Read

Trace

Explain

No modifications.

------------------------------------------------

Level 2

Bug Investigation

Find root cause.

Document findings.

------------------------------------------------

Level 3

Implement a small feature.

Use documentation.

Avoid tutorials.

------------------------------------------------

Level 4

Refactor existing code.

Document reasoning.

------------------------------------------------

Level 5

Design a subsystem.

Explain tradeoffs.

------------------------------------------------

Required Deliverables

Problem Statement

Investigation Notes

Evidence

Decision

Implementation

Verification

Lessons Learned

What I Would Do Differently

------------------------------------------------

Success Condition

Could another engineer follow my reasoning
without needing AI assistance?
